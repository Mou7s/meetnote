## 2026-10-14：本地转写与 DeepSeek

### 发布运行时冲突修复

- Windows 事件日志记录两次 `AccessViolationException`，发生在 `SherpaOnnxCreateOnlineRecognizer`。
- 发布目录的 ONNX Runtime 为 Windows App SDK 带来的 1.23 版本；独立检查程序及 sherpa-onnx NuGet 包使用 1.28.2。
- 编译和发布目标均明确复制 sherpa-onnx 配套运行库，发布结果版本已确认是 1.28.2。
- 实际发布的 WinUI 程序以 `--check-transcriber` 启动，创建窗口后在同一进程加载模型、处理官方样例并正常退出。结果为 PASS，记录在 `%LOCALAPPDATA%\MeetingCompanion\transcriber-check.txt`。该检查不录制麦克风，不调用 DeepSeek。

- sherpa-onnx 1.13.8、中英流式 Paraformer int8 模型已接入；模型存于用户本地数据目录。
- Release 编译通过，0 警告、0 错误；最新代码自包含发布成功。
- 发布程序启动后获得“MeetNote — 会议助手”窗口标题，可在未录音时正常关闭。未做界面截图验收。
- 官方测试音频按 100 ms 音频块送入后台识别，能返回临时文字和确认段落，结束时会刷新剩余文字；重复结束及模型目录缺失检查通过。
- 识别质量存在限制：官方中英混合样例中出现错漏，末尾“星期三”识别为“星期”。上述检查验证数据流和尾部刷新，不代表全文准确率验收。
- DeepSeek 模拟 HTTP 检查通过：密钥请求头、非思考模式、时间戳输入、返回解析与 HTTP 401 错误提示；没有调用真实 DeepSeek API。
- 设置页提供模型路径、凭据管理器密钥、模型名及自动分析开关；自动分析默认关闭。
- README 的模型安装脚本在模型已存在时可重复运行。

仍待验证：真实麦克风连续转写、实际会议识别质量、真实 DeepSeek 密钥与结果、凭据持久化交互、暂停恢复与关闭时的整条界面流程、长时间录制及磁盘故障。说话人区分、历史回放、托盘和快捷键尚未实现。


## 2026-10-19：在线转写、流式分析与阅读交互

### 已完成检查

- 各阶段自包含发布成功；最新版本包含输入音量波形、在线转写、专业词配置、分段分析历史和锁定最新开关。
- 实际发布的 WinUI 程序通过 `--check-cloud-ui` 创建窗口、加载 XAML 与用户设置并退出。此项不是人工界面交互验收。
- 百炼业务空间密钥保存在 Windows 凭据管理器；通过业务空间专属域名获得云端 `task-started`，没有把密钥写入源码或设置 JSON。
- `qwen-audio-3.1-asr-flash-streaming` 实际服务调用通过：约5.6秒公开中文样本返回“开放时间早上9点至下午5点。”，收到确认转写并完成任务收尾。该样本不属于用户会议录音。
- 会议背景配置的任务启动检查通过；具体厂家、工艺和型号词表尚无现场准确率验证。
- `--cloud-protocol` 模拟/纯逻辑检查覆盖任务消息、模型专属参数、远场 VAD、背景与词表传递、去重及数量限制、确认句子、暂停后的时间戳偏移、心跳忽略和缺少密钥。
- 发送时钟的10分钟音频时长模拟检查通过：每包额外调度耗时不再累加到截止时间；网络停顿后的追赶受限。不是10分钟真实网络压力测试。
- `--analysis-stream` 使用模拟 SSE 检查分块累计显示、请求流式标记、截断响应拒绝和取消。没有为该项上传会议内容或调用真实 DeepSeek。
- 分析实现改为只分析新增确认转写，并保存不可覆盖的分段记录；最终总结单独追加。流式草稿不覆盖已完成记录。
- 右侧默认锁定最新；取消勾选可回看，点击查看最新恢复锁定。启动检查通过，连续现场滚动体验仍待人工验收。

### 观察与限制

- 用户已多次反馈本地模型和早期云端模型存在错词，不能把连通性或公开短样本通过当作中文现场会议准确率验收。
- 本地 Whisper large-v3-turbo 在本机一次60秒文件评估中，标准配置约96秒，快速配置约22秒；两者均出现不理想的文字。该结果不代表所有音频或设备，后续按用户要求停止用旧会议录音反复评估。
- 用户报告长时间使用后延迟增大，已修复发送循环可能捕获界面上下文和按包累积额外等待的问题，并增加已发送/待发送指标。长会议端到端延迟改善尚未完成持续实测。
- 历史分析存储、流式生成时的阅读位置和最终总结质量仍需现场验收；旧版覆盖的摘要无法从新版自动恢复。
- 最新改动尚未完成真实会议的完整端到端回归；暂停/恢复弱网场景、设备断开、磁盘故障和长期资源占用也仍需验证。
